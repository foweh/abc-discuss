# 超星学习通 - 全自动讨论回复

在超星学习通课程讨论列表页一键启动，自动遍历所有话题，抓取他人回复内容改写后提交。

## 原理

讨论列表页通过隐藏 iframe 加载每个话题详情页，在 iframe 内抓取已有回复、深度改写（同义词替换+调换句序+随机删句）、填入回复框并自动提交。全程模拟 DOM 操作，不调用任何 HTTP API。

## 安装

Tampermonkey -> 添加新脚本 -> 粘贴 `auto-discuss.user.js` 全部内容 -> Ctrl+S

## 使用

1. 打开超星课程 -> 点击左侧"讨论" -> 进入讨论话题列表页
2. 页面右侧出现 **Auto Discuss** 面板
3. 点 **Start** 开始
4. 观察日志，不想继续了点 **Stop**

## 反检测策略

- 话题顺序随机打乱，不按页面顺序
- 话题间间隔 8-22 秒随机
- 发帖前模拟"阅读"延迟 4-12 秒
- 每 5 个话题后休息 2.5 分钟
- 单次最多处理 30 个话题
- 跳过置顶话题
- 内容深度改写：25 组同义词+调句序+拆句+连词替换

## 常见问题

**需要允许弹窗吗？**

不需要，使用隐藏 iframe 加载页面，不会触发弹窗拦截。

**支持智慧树吗？**

暂不支持，仅覆盖超星域名。
